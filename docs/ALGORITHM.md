# 算法、复杂度与输入契约

实现分为 `statistics.mbt`、`profile.mbt`、`discovery.mbt`。I/O 边界位于 `csv.mbt` 与 `json_api.mbt`；Node 仅提供文件、命令行、HTTP 静态服务与构建适配，网页只负责交互绘制。

**距离**

两个长度 m 的非常量窗口经均值和总体标准差标准化后，使用欧氏距离。常量规则、缺失值和并列规则以 README 为准。自连接使用对称性，只扫描排除区之外的上三角对角线，同时更新两侧窗口的最近邻。AB-join 扫描全部对角线，只更新 source。

**点积递推**

沿一条对角线，下一对窗口点积等于当前点积减去移出的乘积，再加进入的乘积。每 128 次移动重新计算点积，降低累积误差。首个点积使用补偿求和。

**数值处理**

每个输入序列采用统一的平移/正比例缩放以改善大偏置下的条件数。若直接相减溢出，先缩放后相减。窗口统计使用 Welford 累积；未采用易受消减影响的平方和减均值平方公式。若动态范围使一个本来非常量的窗口在条件化后方差坍缩，返回 `E_RANGE`。

对于低方差窗口或几乎相同的形状，用逐样本中心化的直接距离替代 `1-rho` 计算。选中最近邻后再直接核对其距离。返回的是浮点容差下的最近邻；没有声称任意极端条件下严格实数精确。高偏置下输入本身被 IEEE-754 量化的细节无法恢复。

**复杂度**

设 source/target 窗口数为 A/B，窗口长 m。统计预处理为 O((A+B)m)，对角线递推通常为 O(AB)，额外存储 O(n_source+n_target)，不保存 A×B 距离矩阵。周期性重算点积增加约 O(ABm/128) 工作。数值回退的每一对成本为 O(m)，大量相同或低方差窗口可达到 O(ABm)。因此不能把此实现宣称为对所有输入均严格 O(n²) 时间的 STOMP 内核。

单片段查询采用直接标准化距离，时间 O(Bm)。候选提取采用重复扫描，O(kA)。默认限制 k≤100（JSON API），通常只显示 3–4 项。

**资源边界**

- `max_pairs` 为正的 32 位整数，默认 25,000,000。自连接保守检查 A²；AB-join 检查 AB；同时检查各侧 A×m/B×m。计数乘法先转 Int64，避免 Int32 溢出。
- 这是工作量上限，不是严格时间期限。近常量与重复形状可能触发额外回退。浏览器 Worker 可取消，45 秒主动终止；库本身不拥有时钟。
- JSON 边界最多 100,000 样本、8,000,000 个 UTF-16 代码单元。CSV 最多 100,000 数据记录、256 列；CLI 文件上限为 8,000,000 字节。
- 网页最多 5,000 点，真实数据预设的抽样行为明确显示。导入用户数据不自动抽样。
- 常量、排除区覆盖全部邻居、无效窗口及错误都保留独立语义，不把 Infinity/NaN 混进 JSON 输出。

**对照范围**

`scripts/validate_stumpy.py` 检查随机自连接/AB-join、大偏置、小尺度、精确常量、线性、重复和缺失样本。对 STUMPY 显式传入常量掩码，对输入作等价正仿射条件化。距离容差 2e-6×(1+expected)。对返回索引独立计算直接距离，允许并列索引不同。

尚未验证：完整 STUMPY 功能、多变量、流式 egress、所有浮点极值组合、真实故障检测精度。没有从本次 64 组对照推导出通用分类准确率或全生态性能结论。
