# MoonMatrixProfile 项目申报说明

项目名称：MoonMatrixProfile——面向设备时序数据的模式发现与异常分析引擎。

参赛方向：数据处理 / 可复用基础工具库。项目为独立新项目，与 moongpx 无依赖和代码复用关系。

**解决的问题**

设备、服务和能耗数据通常是一长串数值。开发者需要找到相似的工作周期、重复出现的形状，以及偏离常见模式的片段，并能解释判断来自哪些数据。MoonMatrixProfile 将这一需求做成可直接嵌入 MoonBit 项目的基础库，再通过 CLI 与浏览器提供可操作的演示。

**本期实现**

MoonBit 实现自连接与有方向 AB-join、查询距离轮廓、重复模式候选、异常候选、结构化错误、CSV 数值列解析和 JSON 接口。点积采用对角线递推，并包含条件化、稳定统计和数值回退。网页通过 Worker 运行同一份 MoonBit 编译产物，Node 仅承担宿主 I/O，不在宿主中重复实现分析算法。

**评委运行路线**

1. 按 README 运行 `node scripts/verify.mjs`，再运行 STUMPY 固定版本对照。
2. `npm run demo`，在合成信号上选择“重复模式”，查看起点 96 与 336 的零距离片段。
3. 点击“检索选中波形”，观察其在整条序列中的其他匹配，并查看标准化波形证据。
4. 切换“真实数据 · 工业设备温度”，检查原始来源、每 10 点抽样说明和异常候选。
5. 更改窗口、导入本地 CSV/JSON，检查参数失效提示、错误反馈与 JSON 导出。

**质量证据**

本地验证结果与环境记录在 `evidence/`；MoonBit 单元测试、Node CLI/JSON 集成测试、STUMPY 差分对照相互补充。CI 配置用于发布后自动重跑，本地配置存在不等于远程 CI 已通过。

**贡献、许可与边界**

已有 Matrix Profile/STOMP 研究及 STUMPY 作为技术参考与对照，贡献定位为生态实现与工程质量，不宣称算法创新。项目源码 Apache-2.0；第三方数据与验证依赖分别声明。参与者需要理解排除区、常量规则、数值稳定性、复杂度和候选结果的解释边界。

首版是离线单变量分析，异常候选不是设备故障概率。没有提交完整 NAB 检测成绩，没有 GPU/多变量/流式功能，也没有因少量样本测试就声称普适准确率。
